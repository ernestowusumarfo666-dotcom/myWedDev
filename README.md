# FC Mobile HQ

A modern fan website dedicated to FC Mobile players. This project provides information, updates, and resources for the FC Mobile community in an attractive and responsive web interface.

## 🚀 Features

- Responsive design
- Hero banner section
- Modern UI styling
- Image gallery and visual assets
- Mobile-friendly layout

## 🛠️ Built With

- HTML5
- CSS3
